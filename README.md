# Delta bot

Бот @DeltaRossBot помогает вести канал @delta24news. Он присылает Нине в личку черновики постов
с кнопками, публикует одобренные посты в нужное время, по просьбе пишет и правит посты через
нейросеть, делает посты из голосовых и считает, сколько денег ушло на нейросети.

Всё работает на GitHub Actions (бесплатно, без своего сервера). Нейросети подключены через
Polza AI. Состояние бота (очередь постов, вопросы, расходы) хранится прямо в репозитории в виде
файлов, и бот сам их коммитит.

## Что умеет бот

- **Черновики на день.** Бот сам находит 7 свежих позитивных новостей в день, в основном про AI
  и технологии, и вечерний дайджест, и присылает их черновиками на завтра накануне в 21:00 по
  Екатеринбургу (19:00 по Москве), самые актуальные первыми. Если не получилось, пишет:
  «Сегодня черновики не собрались: <причина>».
- **Кнопки под черновиком.** Сверху три даты: сегодня, завтра, послезавтра (предложенная отмечена
  «•»). Нажатая дата ставит пост на случайное некруглое время в этот день (например, 13:19) с 07:00
  до 21:00 по Москве, в самый большой свободный промежуток, так что посты ложатся равномерно, не
  ближе часа друг к другу; дайджест ставится на 22:00–22:15. Точное время: ответ на черновик
  «15:30» или «05.10 15:30». Прошедшее время бот не примет. «Отменить» возвращает кнопки дат.
  «Сейчас»: выйдет сразу. «Изменить»: бот спросит, что поправить, и пришлёт новую версию.
  «Отклонить»: бот спросит почему, и учтёт причину в следующих постах. «Другая картинка» (у постов
  из голосовых): нарисует новую.
- **Ответ на черновик.** `15:30` меняет время, `03.10 15:30` или `завтра 15:30` ещё и дату. Любой другой текст или голосовое считается просьбой
  поправить пост.
- **Просьбы обычным сообщением.** «Пришли 2 новые новости», «сделай пост про новый iPhone».
- **Голосовые и аудиофайлы.** Бот отвечает «Получила, работаю над постом», расшифровывает запись,
  пишет из неё пост голосом Нины, рисует картинку и присылает черновик. Время предлагает ближайшее
  свободное (отмечено «•»); если прислать несколько голосовых подряд, у каждого будет своё время.
  Длинные записи (больше 10 минут) режутся на куски по 10 минут и расшифровываются по очереди;
  бот предупреждает, что это займёт несколько минут. Файлы больше 20 МБ Telegram не даёт ботам
  скачивать, об этом бот скажет сразу.
- **Стиль учится.** Если голосовой пост поправили через «Изменить» и опубликовали, его финальный
  текст дописывается в `style/examples.md` разделом «Голосовой пост после правок». При пересборке
  стиля (`style.yml`) эти разделы сохраняются.
- **Срочные новости.** Если выходит новость, которую сейчас обсуждает весь интернет (новая модель
  OpenAI, Anthropic, Google и т.п.), бот в течение 5–15 минут присылает готовый черновик с
  пометкой «🔥 Срочная новость». Нажми «Сейчас», и пост выйдет сразу. Как это устроено: см. `hot.py`.
- **/cost** — сколько потрачено на Polza AI сегодня и за месяц, с разбивкой: черновики на день,
  просьбы, правки, посты из голосовых, картинки, срочные новости.

## Если что-то сломалось снаружи

- **Telegram не отвечает.** Бот повторяет запрос несколько раз. Если Telegram так и не ответил,
  необработанные сообщения и кнопки остаются в Telegram и обработаются при следующем запуске,
  а посты, которым пора выйти, остаются в очереди и выйдут, когда Telegram оживёт.
- **Polza AI не отвечает, перегружена или кончились деньги.** Бот пишет Нине понятное сообщение
  («Polza AI сейчас не отвечает», «На балансе Polza AI закончились деньги»), а черновику, который
  он правил, возвращает кнопки.
- **Задача идёт слишком долго.** Через 16 минут бот останавливает её сам и говорит об этом (GitHub
  всё равно прервал бы её на 20-й минуте, но молча).
- **Ключи** берутся только из секретов и в логи не попадают: в текстах ошибок токен заменяется на `***`.

## Файлы

Код бота:

- `poll.py` — сердце бота. Забирает из Telegram новые сообщения и нажатия кнопок, ставит посты в
  очередь, публикует те, чьё время пришло, отвечает на /cost. Всё, где нужна нейросеть, передаёт
  в `ai.py`. Запускается workflow `poll.yml`.
- `ai.py` — всё, что делает нейросеть: черновики на день, ответы на просьбы, правки, посты из
  голосовых, новые картинки. Запускается workflow `ai.yml`.
- `polza.py` — общение с Polza AI: текст, расшифровка голосовых (длинные режет на куски через
  ffmpeg), картинки. Каждый запрос записывает свою цену через `costs.py`.
- `costs.py` — учёт расходов: цену каждого запроса из ответа Polza (`usage.cost_rub`) дописывает
  строкой в `costs.jsonl` и собирает отчёт для /cost.
- `send_drafts.py` — отправляет Нине черновики из файла `drafts/<дата>.json`.
- `schedule.py` — московское время, кнопки под черновиком, выбор ближайшего свободного времени,
  случайное время для черновиков дня.
- `tg.py` — общение с Telegram: повторы при сбоях, токен не попадает в тексты ошибок.
- `drafthtml.py` — превращает сообщение Telegram обратно в HTML поста (для правок).
- `save_state.sh` — коммитит и пушит файлы состояния. Если одновременно пушат несколько
  workflow, подтягивает чужие изменения и пробует снова.

Тексты и настройки для нейросети:

- `style-guide.md` — гайд стиля канала (рубрики, формат, длина).
- `style/` — голос Нины: `my-voice.md` (описание), `examples.md` (примеры постов). Собираются из
  выгрузки канала (`result.json` → `posts.txt`) скриптами `build_style.py` и `analyze_style.py`
  через workflow «Channel voice».
- `tone-examples.md` — утверждённые пробные посты, образец тона.

Состояние бота (бот обновляет сам, руками трогать не нужно):

- `queue.json` — посты, ждущие публикации, и их время.
- `pending.json` — вопросы бота, на которые ждёт ответа («Что поправить?», «Почему?»).
- `slots.json` — время, предложенное постам из голосовых, пока Нина его не выбрала.
- `feedback.md` — причины отклонения постов; нейросеть учитывает их в новых постах.
- `images.jsonl` — описания картинок постов из голосовых (для «Другая картинка»).
- `voice_edited.jsonl` — новые версии постов из голосовых после «Изменить» (их финальный текст
  при публикации уходит в `style/examples.md`).
- `costs.jsonl` — цена каждого запроса к Polza AI (для /cost).
- `drafts/` — черновики по дням.
- `.gitattributes` — говорит git склеивать дописанные строки в `feedback.md`, `costs.jsonl`,
  `images.jsonl` и `voice_edited.jsonl`, когда два запуска пишут одновременно.

Workflows (`.github/workflows/`, вкладка Actions на GitHub):

- `poll.yml` («Publish approved posts») — запускает `poll.py`: каждые 5 минут по расписанию GitHub
  и сразу по «звонку» с Cloudflare.
- `ai.yml` («AI tasks») — запускает `ai.py`: в 16:00 UTC (черновики на завтра) и каждый раз, когда `poll.py` передаёт задачу.
- `send.yml` («Send drafts») — отправляет новые файлы из `drafts/`.
- `style.yml` («Channel voice») — пересобирает голос канала, запускается вручную.

Прочее:

- `cloudflare/` — «дверной звонок» на Cloudflare: раз в минуту проверяет, есть ли новые сообщения
  или пост, которому пора выйти, и сразу запускает `poll.yml`. Без него бот отвечает с задержкой
  5–30 минут. Настройка по шагам: `cloudflare/README.md`.
- `hot.py` и workflow `hot.yml` («Hot news») — срочные новости. Каждые 5 минут (по «звонку» с
  Cloudflare, запасной вариант — расписание GitHub раз в 10 минут) бесплатно читает блоги OpenAI,
  Anthropic, Google DeepMind, Google AI, ленты Techmeme и Hacker News. Новые заголовки (если они
  есть) оценивает дешёвая нейросеть Claude Haiku 4.5; только для новости с оценкой 8 из 10 и выше
  основная нейросеть проверяет факты и пишет пост, он приходит обычным черновиком и сохраняется в
  `drafts/<дата>-hot.json`, чтобы дневные черновики его не повторяли. Что уже видено, хранится в
  кэше GitHub Actions, а не в репозитории. Порог и источники: `HOT_MIN`, `SOURCES` в `hot.py`.
- `tests/` — проверки на заглушках, без интернета.
- `CLAUDE.md` — правила для Claude, который правит этот код.

## Секреты

На GitHub: Settings → Secrets and variables → Actions → New repository secret.

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
- `POLZA_API_KEY` — ключ Polza AI (polza.ai, личный кабинет). Без него бот публикует посты и
  понимает кнопки, но не пишет посты сам и не слушает голосовые.
- `GEMINI_API_KEY` — бесплатный ключ Google Gemini (aistudio.google.com → Get API key; из России
  страница открывается только через VPN). С ним черновики на день, просьбы, правки и срочные новости
  делает бесплатный Gemini, а Polza остаётся только для голосовых, картинок и запасным вариантом:
  если Gemini не ответил, бот напишет почему и сделает через Polza. Без ключа всё идёт через Polza.
  Другую модель Gemini можно задать переменной `GEMINI_MODEL` (Variables рядом с Secrets).

На Cloudflare (Settings → Variables and Secrets воркера):

- `TELEGRAM_BOT_TOKEN` — тот же токен бота.
- `GITHUB_TOKEN` — токен GitHub с правом запускать workflow (как его сделать, в `cloudflare/README.md`).

Номер чата Нины (`ADMIN_CHAT_ID`) и канал (`CHANNEL_ID`) записаны прямо в workflow, это не секреты.

## Как перезапустить

- **Бот не реагирует на кнопки и сообщения.** Actions → «Publish approved posts» → Run workflow.
  Если запуск красный, откройте его и посмотрите последнюю строку ошибки. Сообщения не теряются:
  Telegram хранит их сутки, и следующий успешный запуск их обработает.
- **Не пришли утренние черновики.** Actions → «AI tasks» → Run workflow (поле оставить как есть:
  `{"kind": "daily"}`).
- **Черновики сохранились, но не пришли в Telegram.** Actions → «Send drafts» → Run workflow, в
  поле указать файл, например `drafts/2026-10-02.json`.
- **Бот пишет, что кончились деньги на Polza AI.** Пополнить баланс на polza.ai, затем повторить
  просьбу боту.
- **Сменился токен бота или ключ Polza.** Обновить секрет на GitHub (и токен на Cloudflare), затем
  запустить «Publish approved posts», чтобы проверить.
- **Обновился голос канала.** Положить свежую выгрузку в `style/result.json` и запустить Actions →
  «Channel voice» → Run workflow.
- **Ответы приходят с большой задержкой.** Проверить воркер на Cloudflare: открыть его адрес в
  браузере, он покажет результат проверки (`idle`, `new messages: started` или ошибку).
- **Срочные новости приходят слишком часто или не приходят.** Порог `HOT_MIN` в `hot.py` (сейчас 8
  из 10): выше значит реже. Что бот увидел и как оценил, видно в запусках Actions → «Hot news».

## Для разработчика

Проверки без интернета:

```
pip install openai
python -m unittest discover -s tests -v
node --test cloudflare/worker.test.js
```

Для проверки нарезки длинных голосовых нужен установленный ffmpeg (без него этот тест пропускается).
