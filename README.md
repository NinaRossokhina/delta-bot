# Delta bot

Черновики постов для канала @delta24news приходят в личку от @DeltaRossBot с кнопками
«Опубликовать» / «Отклонить». Одобренные посты публикуются в канал.

- `send_drafts.py` — отправляет черновики из `drafts/*.json`. Claude каждое утро добавляет новый файл в `drafts/`, и workflow `send.yml` сразу присылает черновики в Telegram. Если у черновика есть `"time": "12:00"` (по Москве), под ним кнопки времени 09:00 / 12:00 / 15:00 / 18:00 / 21:00 (какую нажать, в то время пост и выйдет), «Сейчас» и «Отклонить».
- `poll.py` — каждые ~5–15 минут (GitHub Actions) обрабатывает нажатия кнопок, ставит одобренные посты в очередь `queue.json` и публикует те, чьё время подошло. Чтобы поменять время, ответьте на черновик сообщением вида `15:30`; любой другой текст в ответ на черновик заменяет текст поста (форматирование сохраняется).

## Секрет репозитория (Settings → Secrets and variables → Actions)
- `TELEGRAM_BOT_TOKEN` — токен от @BotFather
