# Delta bot

Черновики постов для канала @delta24news приходят в личку от @DeltaRossBot с кнопками
«Опубликовать» / «Отклонить». Одобренные посты публикуются в канал.

- `send_drafts.py` — отправляет черновики из `drafts/*.json`. Claude каждое утро добавляет новый файл в `drafts/`, и workflow `send.yml` сразу присылает черновики в Telegram. Если у черновика есть `"time": "12:00"` (по Москве), под ним кнопки времени 09:00 / 12:00 / 15:00 / 18:00 / 21:00 (какую нажать, в то время пост и выйдет), «Сейчас» и «Отклонить».
- `poll.py` — каждые ~5–15 минут (GitHub Actions) обрабатывает нажатия кнопок, ставит одобренные посты в очередь `queue.json` и публикует те, чьё время подошло. Чтобы поменять время, ответьте на черновик сообщением вида `15:30`; любой другой текст в ответ на черновик заменяет текст поста (форматирование сохраняется).

## Что умеет бот
- Обычные сообщения боту («пришли 2 новые новости», «сделай пост про …») — бот (Claude через Polza AI, `ai.py`) находит новости и присылает черновики.
- Под черновиком: кнопки времени, «Изменить» (бот спросит, что поправить, и пришлёт новую версию), «Сейчас», «Отклонить» (бот спросит почему; причины копятся в `feedback.md` и учитываются в новых постах).
- Ответ на черновик сообщением `15:30` меняет время.

## Как это устроено
- `poll.py` (workflow `poll.yml`) читает сообщения и кнопки, ведёт очередь `queue.json` и вопросы бота `pending.json`, публикует посты по времени. Задачи на написание текста передаёт в workflow `ai.yml` (`ai.py`).
- `polza.py` — общие функции для Polza AI (OpenAI-совместимый API, https://polza.ai/docs), через него идут все запросы к нейросетям.
- `cloudflare/worker.js` — «дверной звонок» на Cloudflare Workers: раз в минуту проверяет, есть ли новые сообщения или пост, которому пора выйти, и сразу запускает `poll.yml`. Без него `poll.yml` запускается по расписанию GitHub, с задержками.

## Секреты репозитория (Settings → Secrets and variables → Actions)
- `TELEGRAM_BOT_TOKEN` — токен от @BotFather
- `POLZA_API_KEY` — ключ Polza AI (polza.ai/dashboard; без него бот не пишет посты сам, остальное работает)
